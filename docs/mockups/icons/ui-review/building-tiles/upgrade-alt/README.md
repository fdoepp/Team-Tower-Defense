# Upgrade-Kacheln — Alternativvorschlag (v2)

1. **Titel oben** = Gebäudename  
2. Icons **LvN → LvN+1**  
3. **Stat-Vergleich** mit klarer Einheit **/min**  
   - links grau: aktuelle Produktion  
   - rechts grün: `+Δ`  
4. **Kosten im UPGRADE-Button** (kein separater Gold-Chip)  
   → Tippen = Kosten gelesen + bestätigt  

## Einheiten (aus `PROD_* × productionRate × 60`)

| Gebäude | Einheit | Beispiel Lv1 → Lv2 |
|---|---|---|
| Bierstand | Bier/min | 14 → +6 |
| Fanshop | Fanart./min (+Stimmung) | 24 → +11 |
| Ordnerposten | Sich./min | 22 → +9 |
