# Upgrade-Kacheln — Alternativvorschlag

Layout-Variante zu den bisherigen Upgrade-Karten:

1. **Titel oben** = Gebäudename (nicht „UPGRADE“)
2. Icons **LvN → LvN+1** mit Level-Pills
3. **Stat-Vergleich** darunter:
   - links grau: aktuelle Produktion (`productionRate`)
   - rechts grün: `+Δ` Verbesserung
4. darunter nur noch **Gold-Kosten** + Button **UPGRADE**
5. kein zweiter Name, keine Zeile „Level 1 → 2“
