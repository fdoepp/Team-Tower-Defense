Feedback zur ersten Neugenerierung: Stil zu weit weg vom Original, und Figuren brauchen **vollen Körper** (Beine), damit sie später im Stadion laufen können.

- Stil näher an **Original-Fans** + Bloons-/Toy-Look (dicke Outlines, runde Proportionen)
- **Ganzfigurig** inkl. Unterleib / Beine / Schuhe
- Klare Gimmick-Leiter: Fähnchen → Schal → Mütze → Trikot → große Fahne
- Zuerst nur **Grau**
