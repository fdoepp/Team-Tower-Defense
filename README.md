# LaneLink — Team Tower Defense (Konzept)

Kurzes **2D-Handy-Minigame** (~5 Minuten): zu zweit **Koop auf einer geteilten Map** oder **Versus auf Spiegel-Lanes mit Send Units**.

Grafik bewusst simpel (Flächen, Formen, klare Silhouetten).

## Dokumente

- **[Game Design Concept](docs/GAME_DESIGN.md)** — vollständiges Konzept (Modi, Economy, Towers, Sends, MVP-Scope)

## Modi (Kurz)

| Modus | Idee | Sieg |
|---|---|---|
| **Koop** | Eine Lane, gemeinsames HP, Rollen/Loadouts, Adjacency-Bonus, gemeinsamer Panic | Timer überleben |
| **Versus** | Identische Spiegel-Lanes, Gold → Send-Packs zum Gegner | Gegner-HP auf 0 |
